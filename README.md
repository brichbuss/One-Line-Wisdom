# One-Line Wisdom ✨

A collection of single-sentence wisdom, humor, and advice from contributors around the world.

## How to Contribute
1. Fork this repo.
2. Add **one new line** to `wisdom.txt`. Keep it **exactly one sentence**.
3. Make a pull request.

---

### Example entries:
- "Don’t count the days, make the days count."
- "Coffee first, genius later."
- "Even a stopped clock is right twice a day."
